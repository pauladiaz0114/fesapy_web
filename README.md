# Fesapy — sitio web

Sitio y panel de Fesapy (seguridad industrial, Colombia). Next.js 16 + TypeScript + Tailwind v4 + Prisma + PostgreSQL (Neon), desplegado en Vercel.

## Empezar
1. `npm install`
2. Copiar `.env.example` como `.env.local` y llenar los valores (nunca subir `.env.local`).
3. `npm run dev` y abrir http://localhost:3000

## Antes de subir cambios
`npm run lint` y `npm run build` deben pasar.
